---

## 1. Game Concept (short play loop)

Slalom is a short mobile microgame (~10–30 s) in which the player navigates a character through a procedurally generated sequence of gates.

- **Start:** Countdown timer → gates already present.
- **Play:** Steer left/right (touch/pointer or directional input) to pass through gates while they move toward the player.
- **Success / Failure:** Passing a gate increments score / progress; missing a gate registers failure feedback. Score is evaluated against medal thresholds on completion.
- **End / Replay:** Game ends after a fixed number of gates or time; returns to menu or allows immediate replay via the shared framework.

The microgame is designed to be immediately readable and completable within a WarioWare-style short session.

## 5. Testing Summary (Slalom)

### Expected behaviour
- Countdown displays before gameplay begins.
- Gates spawn according to definition assets and compatibility rules.
- Gates begin moving only after countdown completes.
- Player can navigate through gates using touch/pointer input.
- Pass / miss triggers register correctly and update score / feedback.
- On completion, score is evaluated against medal thresholds.
- Scene navigation returns to the main menu; medals are displayed.

### Actual behaviour
- All of the above observed and confirmed across multiple play sessions.
- Procedural generation produces varied yet valid courses.
- Android builds run successfully.

### Representative issues fixed
1. **UI Canvas physics not firing** → Diagnosed Unity physics limitations on UI; migrated to dedicated 3D play area.  
2. **Invalid / repetitive gate layouts** → Introduced flags-enum compatibility checks and spawn biasing.  
3. **Dynamic recreation errors** → Removed fragile on-destroy recreation; stabilised lifetime management.

### Known limitations
- Gate speed and medal thresholds still use test values and require final balancing.
- Tilt controls planned but not implemented.
- No object pooling yet (potential performance opportunity – see LO5 gap).
